# Worldbuilding for AI Roleplay - Notes From Building

A roleplay world is only as deep as its shared history.

Locations, factions, and secrets give a scene stakes. When the world remembers what happened last time, every conversation inherits weight.

Worldbuilding is not decoration - it is the substrate that makes continuity meaningful.

Build the world once, and it pays rent on every session.

These are the lessons that only show up once you ship. [see it in action at Pogee](https://pogee.ai/).
